# 房间 → 电梯大厅静态场景

`room_elevator.xml` 为本项目自建 MJCF 场景，用于“出门走到电梯门口”。它在原 `elevator_lobby.xml` 大厅南侧增加起始房间，不是 Open-RMF Hotel World 转换。原场景文件保留；电梯、楼层显示/按钮、普通门、长椅和花盆沿用原来的几何与位置。

## 坐标与入口

坐标单位为米，z 轴向上。下列坐标用于仿真装配和离线核验，不作为任务模型的目标坐标输入。

| 项目 | 几何 |
| --- | --- |
| 大厅室内范围 | x=[0,10]，y=[−4,4] |
| 起始房间室内范围 | x=[1,5]，y=[−8.2,−4.2]，4×4 m |
| A2 初始位置 | `[2.3,−6.6,0.55]` |
| A2 初始 yaw | 73°，即约 1.27409 rad |
| 敞开门中心平面 | y=−4.1 |
| 实际门洞 | x=[2.0,4.2]，z=[0,2.4]；净宽 2.2 m |
| 门框前后范围 | y=[−4.25,−3.95] |
| 电梯闭门前表面 | x=9.87，中心 y=1.6，宽约 1.7 m |
| 普通门干扰 | 东墙，中心 y=−2.55 |
| 地面 | 全部共用 z=0 的 `floor`；没有楼梯、台阶或出房门槛 |

大厅南墙及踢脚线在门洞处实际断开，上部保留实体过梁。两片木门完全打开、固定在门洞两侧，没有门关节或开关控制；门叶、门框、凹板和黄铜拉手用于区分真实视觉线索，其中新增的凹板和拉手均不参与碰撞。起始房间西、东、南侧均有 0.2 m 厚实体墙，顶高 3 m；右后侧小书桌不占出口路径。

主端需把该 XML 的 asset/worldbody 合并到现有 A2 模型，并采用上述 spawn/yaw；场景本身不包含机器人或控制器。照明和静态几何随 XML 提供，RGB-D 继续沿用现有无 MSAA 的采集路径。

## 几何验证

CPU 检查通过：MuJoCo 编译为 80 个 geom、0 个 joint，没有执行物理步进或渲染。新增的墙裙、灯具、电梯面板细节、门叶凹板和拉手均显式 `contype="0" conaffinity="0"`，只改变可见外观。

- 当前 A2 三圆包络在任意平面朝向的最大横向宽度为 1.20 m；加入现有体素膨胀及名义硬采样间隙后为约 1.287 m，仍小于 2.2 m 门洞。
- 出生姿态的三圆到最近实体 box 的净空约 0.752 m。
- 从出生相机位置到门洞中心的射线畅通；到电梯两扇门面四个采样位置的射线均被东侧全开门叶或门框挡住。
- 从大厅侧 `[3.1,−3.4,0.65]` 到电梯门面的射线直接命中 `elevator_left_leaf`，没有中间遮挡。是否在当前镜头视野内仍取决于机器人转向，需由真实渲染核验。
- 电梯门叶、普通门、长椅和花盆的原有碰撞 geom 坐标与尺寸保持不变；电梯门前表面仍为 x=9.87。电梯新增的正面中缝与拉丝细线均位于原门面以内或齐平，且不参与碰撞。

完整记录：[geometry_check.json](../../../.local/outputs/task_monitor/scene/geometry_check.json)。这些检查只证明静态装配、净空和选定视线，不代表模型已完成出门或到达电梯。基座跨越 y=−4.1 也不等于整个机器人已经离开门洞。
